# דף הרשמה לליווי מנטלי

אתר סטטי (קובץ `index.html` אחד) + Google Apps Script ששומר כל הרשמה ל-Google Sheet פרטי ושולח מייל עדכון.

## הקמה (כ-5 דקות)
1. צור Google Sheet חדש (פרטי, אל תשתף).
2. בגיליון "לידים – ליווי מנטלי" (כבר נוצר): **תוספים → Apps Script** והדבק את `apps-script/Code.gs`. ה-ID של הגיליון כבר מוגדר בקוד.
3. **פריסה → פריסה חדשה → סוג: אפליקציית אינטרנט**
   - הפעל כ: **אני**
   - מי יכול לגשת: **כל אחד**
   אשר הרשאות (גיליון + שליחת מייל) והעתק את כתובת ה-Web App.
4. ב-`index.html` החלף את `PASTE_APPS_SCRIPT_WEB_APP_URL_HERE` בכתובת.
5. העלה את `index.html` לאחסון: GitHub Pages, Netlify או Vercel.

הגיליון נשאר פרטי: רק הסקריפט (שרץ בשמך) כותב אליו. הכתובת הציבורית מאפשרת רק להוסיף שורה.

אחרי שינוי ב-`Code.gs` צריך **פריסה חדשה (גרסה חדשה)** כדי שהשינוי ייכנס לתוקף.
